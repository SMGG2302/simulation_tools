# simulation_tools

#### 介绍
上机部署的测试工具开发

#### 软件架构
软件架构说明


#### 使用说明

1.  将配置文件config.json放到当前目录下

2.  运行python3 simulated_main_screen.py

3.  弹出UI界面，自动发送布尔数据，勾选send并设置需要的上下界限选择需要测试的功能，点击开始测试按钮，开始测试。

#### 版本历史

1.  version 1.0
    初步实现数据发送和UI界面设计
2.  version 1.1
    修复了数个已知bug，仿真工具通过回环测试，基本可用。
    
3.  version 1.2
    完善了一些功能，action数值可以同时发送，UI界面关闭时整体程序停止。
    
4.  version 1.3
    实现了对配置文件 config.json 的读取与自动化配置流程，使测试工具与上机程序在配置文件上保持高度一致，方便开发与部署。

5.  version 2.0
    转换成了滑条模拟数值的读取和发送，美化了UI界面，补足了所有缺少的bool按钮
    
6.  version 2.1
    设置了重置按钮，在点击后可以回到中值，美化了仿真工具的UI界面，对页面的排版进行了优化。
